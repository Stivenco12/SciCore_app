## Overview

The Física/Química app is a educational tool designed to help users understand and explore various physics and chemistry concepts through interactive simulations and calculators. The app currently includes two main modules:

1. **Spring Simulator**: Demonstrates the behavior of a mass-spring system with damped oscillations, allowing users to adjust the mass, spring constant, and observe the resulting motion and force calculations.

2. **Pressure Calculator**: Provides two modes for calculating pressure - one based on the mechanical formula (pressure = force / area) and another using the ideal gas law (pressure = n*R*T / V).

The app is built using the Kotlin programming language and the Jetpack Compose UI framework, providing a modern and responsive user interface.

## Features

- **Spring Simulator**: Visualize the motion of a mass-spring system with damped oscillations
  - Adjust mass, spring constant, and observe the resulting extension and force calculations
  - See the equilibrium extension, instantaneous extension, elastic force, and weight of the mass

- **Pressure Calculator**: Calculate pressure using two different methods
  - Mechanical pressure: P = F / A
  - Ideal gas pressure: P = n*R*T / V

- **Modern UI**: Sleek and responsive user interface built with Jetpack Compose

- **Educational**: Designed to help users learn and explore physics and chemistry concepts

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/jestcoam/fisica-quimica.git
   ```

2. Open the project in Android Studio.

3. Build and run the app on your Android device or emulator.

## Usage

1. Launch the Física/Química app on your Android device.

2. Explore the available modules:
   - **Spring Simulator**: Adjust the mass and spring constant using the sliders, then observe the simulated motion and related calculations.
   - **Pressure Calculator**: Switch between the mechanical and ideal gas pressure modes, then adjust the input parameters to see the corresponding pressure values.

3. Interact with the app's UI to experiment with the different physics and chemistry concepts.
