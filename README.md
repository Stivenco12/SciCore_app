## Overview

Física/Química is an Android app that provides educational simulations to help students and learners understand physics and chemistry topics. The app currently features two main modules:

1. **Spring Simulator**: Demonstrates the behavior of a mass-spring system with damped oscillations, allowing users to adjust the mass and spring constant.
2. **Pressure Calculator**: Calculates pressure using either the mechanical (Force/Area) or ideal gas (PV=nRT) formula, with interactive sliders to modify the input parameters.

The app is built using Kotlin and the Jetpack Compose UI toolkit, providing a modern and responsive user interface.

## Features

- Interactive simulations for spring dynamics and pressure calculations
- Adjustable parameters to explore how changes affect the system
- Visually appealing and intuitive user interface
- Supports both light and dark color themes

## Installation

1. Clone the repository:

```
git clone https://github.com/jedier-stivenson/fisica-quimica.git
```

2. Open the project in Android Studio.
3. Build and run the app on your Android device or emulator.

## Usage

1. Launch the app on your Android device.
2. Use the tab bar at the top to switch between the "Spring Simulator" and "Pressure Calculator" modules.
3. Adjust the parameters using the sliders or input fields.
4. Observe the changes in the simulation or calculation results.
